# Security

LePa Sentinel runs locally with the user's own rights. It has no network access and edits only Claude Code's user settings, and only with the user's consent.

If you find a security problem, please **do not open a public issue**. Report it privately through GitHub's [Report a vulnerability](https://github.com/emanueleparini/LePa-Sentinel/security/advisories/new) form. We will reply as soon as possible.

Official binaries are code-signed by **LePa s.r.l.** (Azure Artifact Signing) or distributed through the Microsoft Store. Do not run unsigned builds from unknown sources.
